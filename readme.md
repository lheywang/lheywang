## Featured Projects
Here three of my latest projects ! 

### [EtherBench](https://github.com/lheywang/EtherBench)
Program, Debug, Test and power-up any ICs, from the most basic ARM MCU to the latest AMD FPGA in a single open source platform, from board layout to the support graphical app!

### [Sphinx-RTL](https://github.com/lheywang/sphinx-rtl)
Document RTL with this sphinx extension, designed by RTL engineer. Include register maps, IO types, clocks, resets and much more in a single page! 

### [WirelessSpeaker](https://github.com/lheywang/WirelessSpeaker)
A high-end audio speaker, with a GaN based class-D amplifier controlled by an FPGA, and a linux application to provide the wireless streaming and user interfaces!
